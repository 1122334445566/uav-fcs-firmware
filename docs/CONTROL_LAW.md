# 控制律推导

## 1. 符号约定

- NED 世界系 `(N, E, D)`，机体系 `(x_b, y_b, z_b)`，四元数 `q` 把机体向量旋到 NED。
- `φ, θ, ψ` = roll, pitch, yaw（ZYX）；`g = 9.80665 m/s²`。
- 归一化油门 `u_T ∈ [0,1]`，悬停油门 `u_h`；归一化力矩 `τ = (τ_φ, τ_θ, τ_ψ) ∈ [-1,1]³`。
- 仿真中每个电机满油门推力 `T_max = m·g / 2`，于是 `4·u_h·T_max = m·g`（取 `u_h = 0.5`）。

## 2. 推力矢量与小角度近似

四旋翼总推力沿机体 `-z_b`（机体"上"方向）。水平姿态时 `up_NED = (0,0,-1)`。

绕机体 y 轴旋转 θ（NED 下 θ>0 = 机头上仰）：

```
R_y(θ)·(0,0,-1) = (-sinθ, 0, -cosθ)
```

绕机体 x 轴旋转 φ（φ>0 = 右翼下压）：

```
R_x(φ)·(0,0,-1) = (0, sinφ, -cosφ)
```

叠加偏航 ψ 后，单位质量水平加速度（忽略阻力）：

```
a_N / g = -θ·cosψ - φ·sinψ
a_E / g = -θ·sinψ + φ·cosψ
```

**注意符号**：正 pitch（机头上仰）使推力向南（−N）倾斜，所以向北加速需要**负 pitch**。
这与常见"机头下俯向前飞"直觉一致，只是 NED 下 pitch 正方向定义为上仰。

反解得到期望倾角（控制器中的 `fcs_accel_to_tilt`）：

```
θ_sp = -(a_N·cosψ + a_E·sinψ) / g
φ_sp =  (a_E·cosψ − a_N·sinψ) / g
```

再把 `(φ_sp, θ_sp)` 的模长限幅到 `max_tilt_rad`（默认 25°），
对应最大水平加速度 `g·tan(25°) ≈ 4.57 m/s²`。

## 3. 串级结构

```
  p_sp ──►[位置 P+D]──► a_des ──►[倾角反解]──► φ_sp, θ_sp
                                                   │
                            ┌──────────────────────┘
                            ▼
  ψ_sp ──────────────►[角度 P]──► p_sp, q_sp, r_sp
                                     │
                                     ▼
                              [角速率 PID]──► τ_φ, τ_θ, τ_ψ
                                     
  h_sp ──►[高度 P]──► vz_sp ──►[垂速 PI + u_h 前馈]──► u_T
```

### 3.1 位置环（仅 POS_HOLD / AUTO）

```
a_des = Kp_xy · (p_sp − p) − Kd_xy · v          （N、E 两轴独立）
‖a_des‖ ≤ g · tan(max_tilt)
```

默认 `Kp_xy = 1.2 s⁻²`、`Kd_xy = 1.8 s⁻¹`。这是临界阻尼附近的比例-微分：
对 1 m 误差给出 1.2 m/s²，对 1 m/s 速度给出 1.8 m/s² 制动。

### 3.2 角度外环（P）

```
rate_sp_i = clamp(Kp_att,i · wrap_pi(angle_sp,i − angle_i), ±max_rate)
```

`wrap_pi` 处理 ±π 跨越。偏航在 `POS_HOLD/AUTO` 用角度 P；在
`STABILIZE/ALT_HOLD/MANUAL` 直接把摇杆映射成角速率指令（"手动偏航"手感）。

### 3.3 角速率内环（PID，微分作用于测量）

```
e_i      = rate_sp_i − rate_i
I_i     ← clamp(I_i + e_i·dt, ±I_max)
τ_i      = clamp( Kp_i·e_i + Ki_i·I_i − Kd_i·(rate_i − rate_prev_i)/dt , ±1 )
```

用**测量微分**而不是误差微分，避免摇杆突变时的微分冲击（derivative kick）。
积分限幅 `I_max = 0.35` 防止地面/饱和时积分饱和（anti-windup），
并在解锁、模式切换时由 `fcs_controller_reset()` 清零。

### 3.4 高度 / 垂速

```
vz_sp  = clamp(Kp_alt·(h_sp − h), ±max_climb)     （向上为正）
vz     = −v_D                                     （NED 的 D 轴向下）
e_vz   = vz_sp − vz
I_vz  ← clamp(I_vz + e_vz·dt, ±I_vz_max)
u_T    = u_h + Kp_vz·e_vz + Ki_vz·I_vz
```

`u_h = 0.5` 是悬停前馈，让反馈只需修正扰动，避免积分器长期承担重力补偿。

## 4. 控制分配（X 四旋翼）

电机编号（俯视，机头 +x）：

```
        3 (FL, CW)        0 (FR, CCW)
              \          /
               \   +x   /
                [ FCS ]
               /        \
        2 (RL, CCW)      1 (RR, CW)
```

`M[i][·]` = (roll, pitch, yaw) 系数：

| 电机 | roll | pitch | yaw |
| --- | --- | --- | --- |
| 0 FR | −1 | +1 | +1 |
| 1 RR | −1 | −1 | −1 |
| 2 RL | +1 | −1 | +1 |
| 3 FL | +1 | +1 | −1 |

```
m_i = u_T + ½·(τ_φ·M[i][0] + τ_θ·M[i][1] + τ_ψ·M[i][2])
```

- `τ_φ > 0`（右倾）→ 抬左侧电机 2,3；
- `τ_θ > 0` → 抬前侧电机 0,3 → 机头上仰（pitch 正）→ 推力向南（−N），与
  `θ_sp = −a_N/g` 的符号一致；
- `τ_ψ > 0`（NED 顺时针）→ 加速 CCW 旋翼 0,2（反扭矩为 CW = 正偏航）。

矩阵各列正交且 `Σ M[i][k]² = 4`，因此无饱和时可从电机输出精确复原力矩：

```
τ_k = ½ · Σ m_i·M[i][k]
```

SIL 的 `fcs_mixer_torque_from_outputs()` 用同一公式生成机体力矩，
保证"控制器认为自己在发什么力矩"与"仿真物理实际受到什么力矩"方向一致。

### 饱和策略：姿态优先

若 `max(m_i) > u_max`，把所有电机同时减去 `max(m_i) − u_max`；
若 `min(m_i) < u_min`，再全部加上 `u_min − min(m_i)`；最后逐路钳制到 `[u_min, u_max]`。

这样做的效果是**保留任意两路之间的差值**（即滚转/俯仰/偏航力矩），
只牺牲总推力。理由：姿态失控是不可逆的，而短暂推力不足只是掉一点高度。
若反过来按"等比缩放全部电机"，在大机动+高油门时姿态权限会被一起压缩，容易翻机。

## 5. 调参顺序（实机）

1. **断开位置环**，只飞 `STABILIZE`：先调角速率 `Kp → Kd → Ki`，看阶跃响应无超调振荡；
2. 调角度外环 `Kp_att`，目标是指令跟随快且无抖振；
3. **悬停**调 `u_h`（记录 50% 油门是否能维持高度，必要时重标定）与 `Kp_vz / Ki_vz`；
4. 最后接位置环 `Kp_xy / Kd_xy`，从小到大，检查航点切换时的超调与制动距离；
5. 用 `tools/plot_telemetry.py` 观察 `alt/alt_sp`、`pos/pos_sp`、四路电机差量；
6. 每次只改一个参数，用 `fcs_params_save()` 持久化并在 CF 卡/黑匣子里留版本记录。

## 6. 已知简化

- 倾角反解使用小角度近似，25° 以内误差约 10%，在大机动时需用完整旋转矩阵反解；
- 未补偿倾斜造成的升力损失（`u_T / cos(tilt)`），大倾角时高度会轻微下掉；
- 未建模风扰、电机推力非线性（电池电压补偿）、地面效应；
- 航点间为"跳变设定值"，没有轨迹生成/加加速度限制，因此切换瞬间会看到较大位置误差；
- 无 ESC 校准、无电机失效重构（motor failure reallocation）。
